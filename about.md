PromptProof is a GPL v3 library of reusable LLM prompt instructions, preset profiles, and Python tools for combining prompts and exploring model responses. It includes 80 guard templates, 8 profiles, and 49 adversarial prompts.

The tools provide keyword-based checks and optional before/after reports. They do not compute a validated risk index, enforce a sandbox, or guarantee protection from prompt injection or data leakage. Applications must enforce their own permissions and validate outputs. Start with the [README](README.md) and [dated security guidance](docs/security-2026-10-18.md).
